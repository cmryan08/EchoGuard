Event duration sets the fall-like burst, the rapid-movement bout (x3) and the sit-down / stand-up transitions (x1.5). Packet rates below 20 Hz are flagged as insufficient data quality. Simulated packets use the TX MAC 02:51:4d:00:00:00 and every recording, calibration and export made from them is marked synthetic.

Start the data source first. The calibration is stored for the detected sensor configuration (chip, TX MAC, channel, CSI length) and this placement name, and is loaded automatically when that configuration is seen again.
